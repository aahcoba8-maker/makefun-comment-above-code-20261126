One funny, painfully honest line, written as a comment a developer left above
fragile production code:

> `// Do not refactor. The bug this code hides is load-bearing, and it has seniority over you.`

`main.py` (stdlib only) reads `entry.txt` and prints it, writing the text to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when the grader sets that variable.

Run it with:

```sh
python3 main.py
```
